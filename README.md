## 💼 Projetos em destaque

### 🔍 [DevLens — GitHub Profile Analyzer](https://github.com/arthurvicttor/devlens)

**Aplicação Full Stack para consulta e análise de perfis públicos do GitHub.**

- Integração com a **API REST do GitHub** para coleta de informações públicas.
- Consumo de requisições HTTP, processamento de respostas JSON e tratamento de erros.
- Geração e apresentação de indicadores para análise de perfis.
- Separação de responsabilidades entre a lógica de requisições e a interface.

**Tecnologias:** JavaScript · REST API · Full Stack

### 📊 [Sales Data Pipeline](https://github.com/arthurvicttor/sales-data-pipeline)

**Pipeline de dados end-to-end voltado à análise e previsão de vendas.**

- Implementação de processos de **ETL (Extract, Transform, Load)**.
- Limpeza, transformação e preparação de dados.
- Análise exploratória e visualização de indicadores.
- Treinamento de modelo preditivo utilizando técnicas de Machine Learning.

**Tecnologias:** Python · Pandas · ETL · Machine Learning

### 🤖 [Chatbot Educacional Interativo](https://github.com/arthurvicttor/chatbot-educacional)

**Aplicação de interação conversacional voltada a experiências educacionais.**

- Implementação de fluxos de decisão baseados em regras condicionais.
